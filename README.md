# CloudBeacon

CloudBeacon is a cloud-based distributed platform that leverages auto-scaling processing, serving as a centralized manager for scalable applications.

With CloudBeacon, you get a lightweight tool that stays out of your way.

**What you get**

- serving as a centralized manager

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/CloudBeacon.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure CloudBeacon, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
